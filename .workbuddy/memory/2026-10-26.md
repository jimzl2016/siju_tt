## 新增「工作站」首页（16_指挥中心【交互原型】.html）

**需求**：新增工作站页面作为首页；左侧切换工作站时内容自动变化；模型中点击工作站时左侧联动切换；右侧统计不变。

### 导航与模块
- `NAV_ORDER = ["station","orderPlan","equipment","logistics","quality","energy","security"]`，`state.module` 默认 `"station"`。
- `navLabel(k)` 改为直接返回 `MODULES[k].name`（原逻辑是首项固定显示"生产综合"，加首页后会错乱）。
- 新增 `MODULES.station`：左栏 `产线工作站`(wsMonitor, fx1.42) + `工位设备`(wsDevice, fx1.02)；右栏四卡 `生产数据指标`(statKpi) / `产线故障数据`(lineFault) / `设备故障结果`(equipFault) / `质量检测数据`(qualityTrend2)。
- 新增 `WS_DEV`（P01–P12 设备型号/编码/区域/产能/巡检）与 `wsDev(s)` 兜底（2F/3F 的 S/W 工位用 `s.code+"-"+s.id` 生成编码）。

### 左栏（随工位切换）
- `wsMonitor`：12 个 `.ws-chip` 工位切换条（状态点）+ 工位视频（`.vfeed` 用 `IMG+"u71.png"` 按工位 x/y 作 `background-position` 裁切当"机位画面"，叠加 `.vtint` 蓝色压暗 + `.vgrid` 网格 + 取景环 `.vret` + 目标框 `.vbox` + `.vscan` 扫描线 + REC/1080P + 播放键）+ 工步进度条 + 状态行。
- `wsDevice`：小视频缩略（同样用 vfeed）+ 型号/编码/状态 pill/连续运行时长 + 6 项 kv（位置/巡检/产能/节拍/OEE/在线率）+ 参数详情/工艺标准/生产详情按钮。
- 切换只调 `renderLeft()`，**不调 `renderRight()`**，保证右侧统计不变；`wsPlay` 为全局变量，切换工位后保持播放/暂停态。

### 联动
- `selStation(id)`：写 `state.station` → `renderLeft()` → 切换 `#markerLayer .mk[data-st]` 的 `.act` 类 → toast。
- `renderMarkers()` 中 `inStation=state.module==="station"`：工位标记加 `.clickable`/`.act`，点位与标签都可点击，点击走 `selStation`（其它模块仍走 `openStation` 弹窗）；tooltip 增补"点击切换左侧工作站"。
- `setFloor()` 增加：工作站页换层时若当前工位不在该层，自动选中该层首个工位，避免 chips 与模型错位。

### 右栏（固定）
四个新卡片渲染器 + `.rk2/.rkc/.rk3/.dlg` 样式；环形图 `centerSub` 必须传字符串（否则渲染出 "undefined"）；图表 `w/h` 需按 `.chart-box` 实测尺寸传入，否则 SVG 会按 viewBox 比例 letterbox 留白。

### 顺手修复
- `.mk-lb` 由 `left:13px` 改为 `22px`，修复站名标签压住 20px 方形工位号的问题（全模块受益）。
